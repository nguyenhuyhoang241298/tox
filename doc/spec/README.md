# Spec: yêu cầu của dự án

Thư mục này lưu các tài liệu mô tả **dự án cần làm gì**.

## Nên đặt gì ở đây

- Mục tiêu sản phẩm và đối tượng người dùng.
- Yêu cầu chức năng (tính năng, user story, tiêu chí chấp nhận).
- Yêu cầu phi chức năng (hiệu năng, bảo mật, khả năng truy cập, đa ngôn ngữ).
- Phạm vi từng giai đoạn (MVP, các phiên bản tiếp theo).

## Quy ước

- Mỗi tính năng hoặc nhóm yêu cầu là một file Markdown riêng, ví dụ `auth.md`, `lesson.md`.
- Đặt tên file bằng chữ thường, nối bằng dấu gạch ngang.
- Ở đầu mỗi file ghi trạng thái: `Nháp`, `Đang xem xét` hoặc `Đã chốt`.
